# Правила интерфейса HomeBot

- Интерфейс бота — на украинском. Пишите коротко, простыми словами, без технических деталей и повторяющихся пояснений.
- Один шаг — один вопрос. Сохранённые имя и телефон не спрашивайте повторно. Ошибку объясняйте одной короткой подсказкой в чате.
- Навигация между разделами — только на постоянной клавиатуре внизу. Не добавляйте в сообщения «Головне меню», «Мої голосування» и другие кнопки разделов.
- В сообщениях допустимы списки записей, страницы списка, поля формы и действия над конкретной записью.
- Обычные нажатия подтверждайте пустым answerCallbackQuery: без попапов. Важные сведения и ошибки оставляйте сообщением в чате.
- Перед удалением или отключением доступа покажите конкретный объект и две понятные кнопки подтверждения и отмены.
- Не показывайте внутренние ID и номера голосований в пользовательских сообщениях.
- Проверяйте права на сервере при каждом действии. Контакты чужих жителей доступны только администратору в личном чате.
- Не створюйте таблиці чи записи для простих запитів «питання → відповідь», якщо достатньо наявних даних та ID у кнопці. Економте місце в базі.
